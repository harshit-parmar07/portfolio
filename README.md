# Personal Portfolio Website 🌐

A clean, minimalist, and fully responsive personal portfolio designed to highlight software engineering projects, data structures proficiency, and backend/full-stack technical capabilities.

The user interface features a flat, modern dark-mode aesthetic built explicitly without glassmorphism for maximum readability and a high-contrast, professional appearance.

## 🛠️ Technical Stack

- **Frontend & Framework:** Next.js, JavaScript, Tailwind CSS
- **Icons:** Lucide React

## ✨ Key Features

- **Modular Architecture:** Organized using clean component boundaries (`Hero`, `Skills`, `Projects`, `Achievements`, `Footer`).
- **Responsive Layout:** Fully optimized across desktop, tablet, and mobile breakpoints.
- **Performance First:** Built utilizing Next.js optimizations for fast load times and seamless routing.

## 📂 Core Highlights Included

### Featured Projects

- **Natours:** Architected a scalable backend using Node.js and Express.js following MVC design principles, building REST APIs with secure JWT authentication.
- **Full-Stack Issue Tracker:** A production-ready issue tracking software engineered using Next.js, Prisma ORM, and MySQL.
- **Fare Pricing Predictor:** A machine learning regression model leveraging Python and XGBoost to forecast dynamic ride multipliers.
- **Image Caption Transformer:** An end-to-end multimodal deep learning pipeline matching EfficientNet image features to sequential text via Transformers.
- **Game-Hub:** A dynamic video game discovery dashboard engineered with React for high-performance searching and client-side filtering.
- **API Rate Limiter:** A thread-safe, in-memory concurrency protection tool engineered in Core Java implementing the Token Bucket algorithm.

## 🚀 Local Development Setup

Follow these commands to get the development environment running locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
